使用说明
• 每段 = 源音频(src_audio) + 起止偏移，不单独存 wav。
• 听片段：点行末 ▶ 或整行 → 音频从「开始」播放、到「结束」自动停。改了起止后立即试听即可听到新区间。
• 改标签/文本/时间：直接编辑，改动行高亮。
• 删除段：点行末 ✕ 删除整段（删错可用「重置」撤销，但结构性改动已固化，删除前请确认）。
• 新增段 / 合并段：工具栏「+ 段」在选中段后插入空白段（用于把一句拆两句）；「合并↓」把选中段与下一段合并（用于一句被误拆两段时合并回去）。
• 音频来源（最省心方式）：把 音频文件（wav/mp3）拖到「已载入」栏即可试听，拖入的音频直接用于播放，不依赖 json 里的路径写法。也可用「导入 JSON」选择 json 与 wav 同目录的文件夹（自动定位）；或点 ▶ 时按提示选一次音频目录。
• 保存：Chrome/Edge 读写导入时直接写回原 segments.json（文本与音频始终一致）；否则下载 JSON 供手动覆盖。
